# Editor Examples
Here are various usage examples of React Timeline Editor to help you quickly understand and master the various features of the component.

## 🚀 Basic Features

### Basic Usage
Demonstrates the basic functionality of the timeline editor, including drag, scale, and other basic operations.

### Action Preview
Shows a client-controlled preview of a future action before it is added to timeline data.

### Action Configuration
Shows how to configure the movability, resizability, and movement range limitations of actions.

### Custom Style
Demonstrates how to customize the appearance of action blocks through custom render functions and CSS styles.

## 🎯 Interactive Features

### Grid Snap
Enable grid snapping to align action blocks precisely according to grid units.

### Auxiliary Line Snap
Demonstrates auxiliary line snapping, automatically aligning to other actions or cursor positions when dragging.

### Auto Scroll
Automatically scrolls the timeline to show more content when dragging exceeds the visible area.

### Collapsible Rows
Rows can collapse while idle and expand when hovered or actively edited.

## 📊 Advanced Features

### Basic Event Handling
Shows how to handle click, double-click, right-click, and other events for actions and rows.

### Move & Scale Callbacks
Demonstrates how to control drag behavior through callback functions to implement custom interaction logic.

### Scale Customization
Shows how to customize the display and style of time scales.

### Scroll Sync
Demonstrates how to synchronize scrolling between the timeline and other components.

## 💡 Usage Tips
- Each example includes complete code implementation
- You can directly copy the code to use in your project
- It is recommended to learn in order from basic to advanced
- All examples support real-time preview and interaction

Start exploring these examples to quickly master the powerful features of React Timeline Editor!
