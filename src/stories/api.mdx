### TimeLineEffectSource

> Editor effect execution code data structure

- start trigger condition
  - Triggered when the runner starts playing, if the time is within the current action's time range
- enter trigger condition
  - Entering the current action's time range from a non-action time area
- update trigger condition
  - Triggered every frame when playing the current action (including reRender)
  - Triggered during reRender
- leave trigger condition
  - Leaving the current action's time range
- stop trigger condition
  - Triggered when the runner pauses, if the time is within the current action's time range
